☁ Cloud save

Cloud save keeps your guides in a private GitHub repository, so you can open them on any computer.
  1. First time only: create a private repository named guide-saves (leave everything else as is, then click Create repository).
  2. Create an access key (token): give it a name such as "Guide app – work PC", set Expiration, choose Repository access → Only select repositories → guide-saves, then under Repository permissions set Contents to Read and write. Click Generate token and copy it.

Do this on each computer you use. The token is kept only in this browser; click Disconnect on shared computers when you're done.
